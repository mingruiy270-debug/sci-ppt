# 语义组件

原生母版优先保留：先完成模型正常绘制，再将相关原生形状或线稿组合，导出 SVG/PNG 仅作复用副本，不把副本回插替换母版。组件格式不得反向驱动原生绘制降级为裁图。

路线由模型按视觉结构和编辑价值判断。示意轮廓通常适合路径；照片、实验影像和纹理保留真实像素，背景能可靠分离即可去背景。混合对象可原生主体加栅格效果。已有独立源资产优先复用，但参考页局部裁片须检查是否含邻接文字、箭头或背景污染，不能因像素相似就接受。决定栅格时在已有工作信息中保留一句用途原因即可，不创建报告或用户确认步骤。

后处理前后核对原生对象引用和类型，不能因分组或导出消失并变为图片。导出失败先修复导出方式或使用源矢量，不把原生组件改标为 raster 来绕过失败。用户指定路线修改时保留未变化组件，更新目标组件的 SCI_KIND 与相应资产，避免旧格式资源误当成新版。

已有后处理前 PPTX 时可为快检加 `--baseline before.pptx`，检测原生对象 ID 丢失；不要求专门保存额外副本。ID 被工具重写也会提示，需辨别，不能将其当作视觉保真证明。若组件内部有普通标签、箭头残留，结合最终预览局部复看，不能只靠 Alpha 判定合格。

复用制作过程中已有结构。组件最少保留稳定 ID、语义名、页面与对象引用、形式及现有源文件。ID 不随插入对象重新编号。替换需要时才记录原始边界框和连接锚点。

安全时使用原生组。跨图层或与外部连接交错时保留逻辑组件：同页多个对象共享 ID，不改变其 z-order。替换先保留旧对象的位置、比例和前后邻居，插入新组件并更新相关连接，通过局部检查后移除旧对象；失败恢复原组件。仅移动和缩放不代表内部可编辑。

## PowerPoint 对象关联

优先使用现有源资产。需要从 PPT 导出时，可在顶层 Shape 或 Group 的 `Tags` 写入：

- `SCI_ID`：稳定 ASCII ID，例如 `c001-neuron`；同页同 ID 的多个顶层对象构成逻辑组件。
- `SCI_KIND`：`vector`、`raster` 或 `mixed`，同组件必须一致。
- `SCI_ORDER`：正整数导出顺序；省略时按稳定 ID 排序。

示例：`$shape.Tags.Add('SCI_ID','c001-neuron')`。组内部不要重复标记。复制组件应获得新 ID；替换保留原 ID。可额外使用 `SCI_NAME` 保存语义名称；源码已有对应结构时不强制重复写标签。

兼容旧名 `CMPV_001_name` / `CMPR_002_name`。导出器先收集再排序；检测跨页 ID 冲突和类型冲突；逻辑组件使用 ShapeRange 导出，不对生产页执行分组。

```powershell
powershell.exe -NoProfile -File scripts/export_components.ps1 -PresentationPath 'D:\work\Final_editable.pptx' -OutputDirectory 'D:\work\Components'
```

脚本依赖 Windows 桌面 PowerPoint 和 Windows PowerShell 5.1，读取当前打开版本，不保存或关闭用户演示文稿。导出目录已有同名文件时默认报错；确认属于本次改动组件后可加 `-Overwrite`，用 `-ComponentId` 仅导出指定稳定 ID。

vector 导出 SVG+PNG；raster 导出 PNG；mixed 导出合成 PNG，另由模型复用已存在的独立 SVG/PNG 子资产。混合 PNG 不声称内部可编辑。SVG 导出失败或含 image/foreignObject 时失败，不把它降级成“纯矢量成功”。需要模型重新选择正确类别或复用真实源文件。

紧边界导出不能保证边缘无污染，须在最终预览中看一次。保留属于对象的效果，排除外围标签与箭头。复杂矢量只有实际卡顿、膨胀或失败时才简化局部路径或分离纹理；使用 SVG 本身不会减少路径复杂度。

当前项目只复用已验证且未修改的源资产。跨会话确需恢复时可保留私有小索引，不交付，不做同名语义的跨项目自动替换。
